## 二、转换管线（LLM 主交付 + OCR 离线降级）

PyMuPDF 渲染(150 DPI) → 视觉大模型整页提取（文字块+bbox+颜色+加粗+语义类别）→
本地 OCR 逐行交叉仲裁（长度不一致用墨迹连通域字形数裁决，争议行放大复读）→
像素分析（真实字体度量拟合字号/字距，PIL + Microsoft YaHei）→
双策略擦除（平滑背景逐行线性插值；复杂/彩色背景仅字形像素紧致 TELEA 修复）→
python-pptx 重建（整页背景 Picture + 逐行原生文本框）。

## 三、元素还原情况（类型 / 还原结果 / 可编辑性）

| 元素类型 | 还原结果 | 可编辑性 |
|---|---|---|
| 正文 / 标题 / 多行段落 | ✅ 原生文本框，位置/字号/颜色/加粗自动还原，字距撑满原宽度 | 可选中、改写、改字体字号颜色 |
| 页码（01、02、3、4、5、6…） | ✅ 原生文本框（放大复读取数字真值） | 完全可编辑 |
| 页眉 / 页脚（公司名、标语） | ✅ 原生文本框 | 完全可编辑 |
| 目录条目编号与页码 | ✅ 原生文本框 | 完全可编辑 |
| 封面主标题 / 副标题 | ✅ 原生文本框（字形紧致擦除，插画无损） | 完全可编辑 |
| 图表数值标签（数据点、轴刻度、百分比） | ✅ 原生文本框；擦除仅限字形像素，折线/柱形无损 | 完全可编辑 |
| 图表本体（折线、柱形、坐标轴）、图标、装饰图形 | ⚠️ 原样保留在背景图中 | 不可单独编辑 |
| 无墨迹 / 极小文字（防幻觉保护） | 原样保留在背景图中 | 不可编辑 |
| 整页背景（插画、照片、渐变） | ✅ 独立 Picture 对象 | 可整体选中、移动、缩放、替换 |

**无法结构化还原的根因**：源 PDF 每页是单一位图（无矢量绘图对象、无文字层），
图形/图表/表格的矢量结构在生成时已丢失；程序化重建语义结构不可靠，
按题目"暂时无法结构化还原的复杂视觉内容采用独立图片对象保留"执行。

## 四、验证结果（实测）

1. 可编辑性探针：169/169 文本框改写-恢复全部通过。
2. 黑框检测 0 处；残留重影检测 0 处。
3. 折线图完整性：p8 绘图区 8461 个彩色图形像素仅 7 个受影响（0.08%）。
4. 页码真值：第 2–9 页 01/02/01/02/3/4/5/6 全部正确。
5. 视觉保真度：非文字区域像素偏差<12 的比例平均 96.1%。
6. 兼容性：PowerPoint COM 成功打开并导出全部 10 页；WPS 可直接打开（标准 OOXML）。
7. OCR 离线模式：165 个可编辑文本框 + 1 保护；探针 165/165（无 API 消耗）。
8. 在线 Demo：公网地址实测上传→转换→下载 HTTP 200（`x-stats: slides=1;texts=10`）。
